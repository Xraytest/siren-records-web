# 宣传片 v2 · 制作说明（播放器主题 · 配音无配乐）

线上站：<https://siren-records-web.chengqing-2008.workers.dev>
成片：`promo/siren-promo-v2.mp4`（1920×1080 / 30fps / 45.7s / H.264 + AAC 48kHz）

主题：**一个好用的第三方塞壬唱片播放器**。全片只有旁白，没有背景音乐。

## 画面：线上站真实操作

`capture.mjs` 用 Playwright 驱动 Edge 访问线上 workers.dev（经本机 `http://127.0.0.1:10808` 代理），
带演示账号 `demo_archive` 的登录态，并且**每轮都用全新 profile**——否则上一轮留下的播放队列会让底栏一开场就在播，
而这条故事线要的是「s4 点了播放整张之后，底栏才出现」。

| 段 | 时长 | 真实动作 |
|---|---|---|
| s1 | 3.18s | 首页首屏，底栏尚未出现 |
| s2 | 5.02s | 下滚到统计条 298 / 911 / 3 / 1 |
| s3 | 5.18s | 档案封面墙 + 真实检索「月」 |
| s4 | 3.28s | 点开「昨日海OST」→ 真点「播放整张」，底栏与正在播放同时出现 |
| s5 | 6.58s | 点底栏展开播放器 → 歌词页（真 lrc 逐行）→ 切到队列 5 首 |
| s6 | 5.78s | 我的歌单（3 张真实歌单） |
| s7 | 3.40s | 偏好设置 → 真点「屏蔽伴奏音乐」开关（录完自动复原） |
| s8 | 4.90s | 账号页 CREW FILE / SERVER / D1 |
| s9 | 5.96s | 片尾卡 `endcard.html`（Edge 截图渲染） |

抓帧按**帧预算**（旁白时长 × 15fps）采集，合成时按段均分到 30fps 时间线，机器快慢不影响音画对齐；
导航跳转的间隙在 `build_base.mjs` 里剪掉。

旁白总长 41.7s；每句起点 = 段起点 + 0.3s，句末正好落在段末，**段间是真空档**（约 -91dB），
所以不需要配乐来填缝，这也是去掉背景音乐后仍然不显得断的原因。

## 字幕与响度

- ASS 底部居中：`Noto Sans SC` 46px、青色 `#a0edff`、半透明底框（BorderStyle 3）、Outline 14。
- 只有旁白轨：先量 `mix_raw.wav`（-17.6 LUFS / TP -3.9 dB），补 +1.6 dB 静态增益 + `alimiter=0.94`；
  成片 **I -15.4 LUFS / True Peak -1.8 dBFS**。

## 复现

```bash
cd promo
PROXY_URL=http://127.0.0.1:10808 node capture.mjs        # 真实操作抓帧（会重建 profile 与 frames）
FFMPEG=... node build_base.mjs                            # 拼帧 + 片尾卡 → build/base.mp4
FFMPEG=... FFPROBE=... node assemble.mjs                  # 旁白 + 字幕，无配乐
```

## 已知限制

- 抓帧是 15fps 采样插到 30fps（不是逐帧录屏），滚动时有轻微步进感；这是为保持旁白对齐的取舍。
- 画面里的 `demo_archive` 是演示账号，它的 3 张歌单与 1 条广场条目留在线上 D1 供录制使用。
- 站点页脚的「ARCHIVE BUILD / 2026-10-22」是站点自身构建戳，未随本次部署刷新。
- 本次录制期间本机 ProxyGate 网关已停，改用 `127.0.0.1:10808`；ProxyGate 恢复后可用回 `65532`。
