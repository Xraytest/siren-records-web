## 混音与响度

无配乐，只输出旁白轨：

- 先量混音（-17.5 LUFS / TP -3.6），补 +1.5 dB 静态增益 + `alimiter=0.94`；
  成片 **I -15.5 LUFS / True Peak -1.5 dBFS**。
- 实测旁白结束后（66.4s 起）为**数字静音 -91dB**，段间空隙亦为 -91dB（个别 -36~-43dB 为旁白尾音拖尾）。

## 复现

```bash
cd promo
node capture.mjs                                          # 抓帧（BASE_URL 默认 siren.neolx.ltd）
FFMPEG=... node build_base.mjs                            # 拼帧 + 片尾卡 → build/base.mp4
FFMPEG=... FFPROBE=... node assemble.mjs                  # 无配乐终混（不设 BED / MUSIC）
```

若要配乐版：`BED=build/msr_bed.wav node assemble.mjs`（音床由 `fetch_msr.mjs` + `build_msr_bed.mjs` 生成）。

## 已知限制

- 时长 70.6s 超出 60s 目标较多（旁白 64.6s + 片尾卡 4.2s）；若要压到 60s 需再砍约 10s 旁白。
- 抓帧是 15fps 采样插值到 30fps，滚动时有轻微步进感。
- 首屏偶发 `ERR_CONNECTION_CLOSED`，`capture.mjs` 已加重试（4 次 × 1.5s）。
- 录制会在 D1 真实创建/导入歌单，已清理重复项并恢复演示歌单原始状态。
- 站点页脚的「ARCHIVE BUILD / 2026.10.22」是曲库快照自身时间戳，不随部署刷新。
